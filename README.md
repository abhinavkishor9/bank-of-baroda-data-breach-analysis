# Bank of Baroda Data Breach Analysis

## Overview

This repository contains an independent SOC/DFIR analysis of the reported Bank of Baroda cybersecurity incident involving an employee email compromise and the alleged exposure of approximately 3 TB of organizational data.

Unlike a traditional incident summary, this case study focuses on reconstructing possible attacker behavior using publicly available information while distinguishing confirmed facts from investigative hypotheses. The analysis evaluates multiple attack paths, identifies the evidence required to validate each scenario, and demonstrates how a Security Operations Center (SOC) would investigate such an incident.

> **Disclaimer:** This repository is based solely on publicly available information. Any attack paths discussed are investigative hypotheses and should not be interpreted as confirmed attacker activity.

---

## Objectives

- Analyze the confirmed employee email compromise as a potential initial access vector.
- Evaluate plausible attack paths that could explain the reported data exposure.
- Demonstrate a structured SOC investigation methodology.
- Identify the forensic evidence required to validate each attack scenario.
- Explain the challenges of recovering data after public exposure.
- Provide practical security recommendations based on investigative findings.
